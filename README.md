# Serenity Spa (arm 4)

Design-forward static landing page for Serenity Spa. Next.js App Router
(`output: 'export'`) + Tailwind + shadcn-style CSS variable tokens, following the
design system in `design-system/serenity-spa/MASTER.md`.

## Local verification

```bash
npm test
```

## Build

```bash
npm install && npm run build   # static export to out/
```
